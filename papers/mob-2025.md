# Why 1 + 1 < 1 in Visual Token Pruning: Beyond Naïve Integration via Multi-Objective Balanced Covering

[← 返回目录](../README.md)

- **作者**：Yangfu Li, Hongjian Zhan, Tianyi Chen, Qi Liu, Yu-jie Xiong, Yue Lu
- **发表**：NeurIPS 2025
- **链接**：[Paper](https://arxiv.org/abs/2505.10118) · [Code](https://github.com/YChenL/MoB)
- **收录日期**：2026-10-26

## TL;DR

- **动机**：视觉 token 剪枝有两个目标：视觉保留（VP）和提示对齐（PA）。现有多目标方法用固定策略把两者揉在一起，结果并不比单目标方法好（1+1<1），原因是两个目标的相对重要性会随 prompt 与图像的耦合程度变化。
- **方法**：基于 Hausdorff 距离推导出剪枝的首个闭式误差界，再用 ε-covering 理论刻画两个目标之间的权衡；据此提出免训练的 MoB，把剪枝重构为双目标覆盖问题，用贪心的“半径交换”把权衡转化为预算分配，复杂度随 token 数线性增长。
- **效果**：LLaVA-1.5-7B 只保留 11.1% 视觉 token 仍保持 96.4% 性能；LLaVA-Next-7B 加速 1.3–1.5×，性能几乎无损；可直接用于 Qwen2-VL 和 Video-LLaVA。
