# Awesome Paper Figures

个人收藏：图画得好的论文，方便画图时找参考。

- 数据源：[`papers.yaml`](papers.yaml)，图片存放在 `figures/<paper-id>/`
- 修改后运行 `python3 scripts/build_readme.py` 重新生成 README、论文页和画廊页（依赖 `pyyaml`、`pillow`；请勿手动编辑生成的文件）

共收录 **7** 篇论文，**67** 张图。
